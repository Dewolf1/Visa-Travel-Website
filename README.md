## 🎯 Overview

Premium Travel Visa Website is a full-featured platform that simplifies the visa application journey. Users can browse visa requirements, submit applications, track status, and get expert guidance—all in one place.

## ✨ Features

- **Visa Information**: Browse comprehensive visa requirements by country
- **Application Portal**: Submit visa applications with intuitive forms
- **Status Tracking**: Monitor application progress in real-time
- **Country Guides**: Detailed travel guides and requirements by destination
- **Responsive Design**: Seamless experience across desktop, tablet, and mobile devices
- **User-Friendly Interface**: Clean, modern UI built from professional design specs

## 🛠️ Tech Stack

- **Frontend Framework**: React/Next.js
- **Styling**: CSS/Tailwind CSS
- **Build Tool**: Vite
- **Package Manager**: npm

## 📦 Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** (v16.0.0 or higher)
- **npm** (v7.0.0 or higher) or **yarn**

## 🚀 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Dewolf1/Visa-Travel-Website.git
   cd Visa-Travel-Website
   ```

2. **Install dependencies**
   ```bash
   npm i
   ```

3. **Set up environment variables** (if applicable)
   ```bash
   cp .env.example .env.local
   # Edit .env.local with your configuration
   ```

## 💻 Development

### Start the development server

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or the port specified in your configuration).

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
